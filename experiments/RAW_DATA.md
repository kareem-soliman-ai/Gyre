# Raw Experiment Data

The public repository keeps preregistrations, executable scripts, run order,
aggregate tables, analyses, summaries, and failed-gate receipts.

Raw per-generation and per-judgement bundles for EXP-01 through EXP-04 are not
distributed in the Git repository. They produced impractically long Windows
paths, added more than 500 low-level files to a five-minute teaching repository,
and include untrusted model-generated text that requires a separate publication
review.

The maintainer retains an immutable tar capture:

```text
SHA-256 e5afb6e41a3e533b2fb2136aeee2804f03878132f14a3d84ac1e61d1ac7e8fcb
files   513
bytes   12,000,108 before tar packaging
```

This is a custody receipt, not public reproducibility. Any claim requiring those
raw records must remain bounded accordingly until a reviewed data package is
published separately.
