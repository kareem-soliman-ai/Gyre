# Changelog

## 1.2.0 - 2026-07-28

- Treats observation and verification as possible interventions on the object,
  control mechanism, evaluator, human, or later evidence.
- Requires a no-probe or renewable-negative-control comparison when causal
  quietness is not established.
- Separates immutable latent-variable IDs from participant-created names and
  requires names to earn value through prospective prediction rather than
  vocabulary matching.
- This version is unqualified. EXP-02 evaluated version 1.1.0 and must not be
  reused as promotion evidence for 1.2.0.

## 1.1.0 - 2026-07-28

- Evolves the skill from EXP-01's failed qualification: 11/18 blind votes
  favoured the skill, but unsafe-authority and token-efficiency gates failed.
- Requires machine-checkable task constraints and evidence for any
  `calibrated` sensor label.
- Makes `prompt_contracts` inside the JSON spec canonical, aligns maturity
  spelling with the validator, and prohibits risk notes from excusing invalid
  high-consequence authority.
- Adds a compact-output recipe to reduce graph theatre and duplicated prose.
- Validated against the observed incident-response failure and the original
  fixed-loop regression fixture; no clean-context behavioural rerun was made.

## 1.0.0 - 2026-07-28

- Initial public release.
- Extends the earlier single-loop contract with graph topology, typed
  coordination, capability-by-consequence authority, separated prompt roles,
  shadow-mode adaptation, switching costs, and Link A/B/C evaluation.
- Adds a standard-library validator and a portable JSON design template.
